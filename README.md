# Calculadora de Matrizes

Projeto desenvolvido em linguagem C.

## Funcionalidades
- Cadastro de duas ou mais matrizes.
- Adição de matrizes.
- Subtração de matrizes.
- Verificação de dimensões.
- Menu para realizar novas operações ou sair.

## Como executar

gcc calculadora_matrizes.c -o calculadora

./calculadora

## Linguagem utilizada
C
